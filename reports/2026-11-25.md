## 7. Where improvement is needed

1. **Account number** — 17 OCR errors in last 7 days. Shipping account number — wrong/missed carrier account; prefer the explicitly labelled 'Acct #' / FedEx/UPS account field and validate digit length.
2. **Part ID / Product ID not captured or wrong** — 16 OCR errors in last 7 days **(rising)**. Part/Product ID capture — look at multi-line and table-wrapped item codes; add PPC catalog validation for unmatched IDs.
3. **Ship-to name duplicated as company name** — 12 OCR errors in last 7 days **(rising)**. Ship-to attention name is being copied into Company Name — add a rule: if no company is on the PO, leave company blank (or use distributor), never the contact name.
4. **Order type** — 9 OCR errors in last 7 days **(rising)**. Order-type classification — add examples of the misclassified cases to the prompt.
5. **STC (State To Credit)** — 9 OCR errors in last 7 days **(rising)**. STC extraction — check the prompt/rule that reads state-to-credit from the PO header/ship-to state.
- Rising: **Quantity** (3 → 5). Quantity parsing from size grids / multi-line items.
- Rising: **Ship date / PSST / in-hands** (1 → 5). Preferred ship date logic — align with the new PSST rules.
- Accounts to fine-tune first (most repeated OCR errors this week): Helm Promotions - MI, 4Imprint, Halo Branded Solutions, American Solutions for Business, Geiger - Headquarters.
- PO-side issues are not OCR bugs but drive overall accuracy; top drivers: Color not on PO / not in PPC (34), Size (13), Shipping address missing / wrong (12). Consider default rules (e.g. nearest PPC color, distributor address fallback) so these stop needing manual review.
